# Історія змін

## 1.0.1 — 25.10.2026

- Додано файл `render.yaml`: сайт розгортається на Render за одним посиланням, Render питає лише ключ API та пароль.

## 1.0.0 — 25.10.2026

Перша публічна версія.

- Три способи пошуку: за словесним позначенням, за зображенням і комбінований; клас МКТП обов’язковий (до трьох класів).
- Вибір території: усюди, Україна, ЄС, США.
- Перелік офіційних сайтів і авторизованих продавців, які не позначаються як порушення.
- Три паралельні напрями пошуку: схожі позначення; маркетплейси й магазини; компанії, домени й соцмережі.
- Для кожного збігу: посилання, тип можливого порушення, рівень ризику, позначення на сторінці, за чим збіг і пояснення.
- Перевірка посилань: залишаються лише адреси, які справді повернув вебпошук.
- Фільтри за ризиком і типом, завантаження CSV, копіювання переліку.
- Захист: ключ API лише на сервері, необов’язковий пароль доступу, ліміти запитів на годину й на добу.
