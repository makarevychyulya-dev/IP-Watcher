# Пошук порушень прав на торговельну марку

Сайт для автоматизованого пошуку в інтернеті можливих порушень прав на торговельні марки. Користувач вводить словесне позначення, завантажує зображення знака або робить обидва, обирає клас МКТП і територію. Сервер через Claude API з вебпошуком шукає ідентичні та схожі позначення, пропозиції на маркетплейсах, можливих неавторизованих продавців і використання третіми особами. Для кожного збігу сайт показує посилання на сторінку, рівень ризику й пояснення, чому це може бути порушенням.

Кожне посилання в результатах перевіряється: сервер залишає лише ті адреси, які справді повернув пошук. Візуальна схожість оцінюється за описом знака, а не попіксельним порівнянням зображень.

## Що потрібно

- акаунт на GitHub (безкоштовний), щоб зберігати код;
- акаунт на Render (безкоштовний), щоб сайт працював в інтернеті;
- ключ Claude API і поповнений баланс у Claude Console (platform.claude.com). Пошук оплачується з цього балансу: за кожен вебпошук і за обсяг тексту.

## Найкоротший шлях: два кроки

1. Завантажте вміст цієї папки в новий **публічний** репозиторій на GitHub з назвою `trademark-watch` (покроково — у розділі «Код на GitHub» нижче).
2. Відкрийте посилання, замінивши `ВАШ-ЛОГІН` на свій логін GitHub:

   `https://render.com/deploy?repo=https://github.com/ВАШ-ЛОГІН/trademark-watch`

   Увійдіть у Render через GitHub, вставте ключ Claude API в поле `ANTHROPIC_API_KEY`, придумайте пароль для `ACCESS_PASSWORD` і підтвердьте розгортання. Render усе налаштує сам за файлом `render.yaml`, а за 3–5 хвилин покаже адресу сайту.

Нижче той самий процес описано докладно, зокрема ручне налаштування Render.

## Розгортання вручну за 15–20 хвилин

### 1. Ключ Claude API

1. Увійдіть на platform.claude.com.
2. Відкрийте Settings → API keys і натисніть Create key.
3. Скопіюйте ключ (починається з `sk-ant-`). Консоль показує його лише один раз.
4. Поповніть баланс і за можливості встановіть ліміт витрат.

### 2. Код на GitHub

1. На github.com створіть новий репозиторій, наприклад `trademark-watch` (можна приватний).
2. На сторінці порожнього репозиторію оберіть «uploading an existing file».
3. Розпакуйте архів проєкту й перетягніть у вікно **вміст** папки `trademark-watch` (файли `server.js`, `package.json` і папки `config`, `lib`, `public`), а не саму папку чи архів.
4. Натисніть Commit changes.

Файл `.env` на GitHub не завантажуйте: ключ зберігається лише на Render.

### 3. Сайт на Render

1. Увійдіть на render.com через GitHub.
2. Оберіть New → Web Service і підключіть свій репозиторій.
3. Заповніть поля:
   - Language: `Node`
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance Type: `Free`
4. У розділі Environment Variables додайте:
   - `ANTHROPIC_API_KEY` — ваш ключ;
   - `ACCESS_PASSWORD` — пароль для сайту (рекомендовано, щоб вашим балансом не скористалися сторонні).
5. Натисніть Deploy. Через кілька хвилин сайт буде доступний за адресою на кшталт `https://trademark-watch.onrender.com`.

**Важливо про безкоштовний план Render:** сервіс «засинає», якщо 15 хвилин ним ніхто не користується. Перше відкриття після цього триває до хвилини. Перед презентацією відкрийте сайт заздалегідь.

## Налаштування

Змінні середовища задаються на Render у розділі Environment:

| Змінна | Що робить | Типово |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | ключ Claude API (обов’язково) | — |
| `ACCESS_PASSWORD` | якщо задано, сайт питатиме пароль перед пошуком | немає |
| `RATE_LIMIT_PER_HOUR` | запитів до Claude з однієї адреси за годину; одна перевірка — це 3–4 запити | 30 |
| `DAILY_LIMIT` | запитів до Claude на весь сайт за добу | 300 |
| `ANTHROPIC_MODEL` | модель Claude | `claude-sonnet-5-5` |

Якщо пошук повертає помилку про відхилений запит, перевірте в Claude Console, що для вашої організації дозволено вебпошук, а журнал на Render (вкладка Logs) покаже подробиці.

## Як вдосконалювати сайт

Після кожної зміни на GitHub Render автоматично перевстановлює сайт за 2–3 хвилини. Номер версії внизу сторінки показує, що оновлення вже діє.

Робочий цикл із Claude:

1. Завантажте поточну версію: на GitHub натисніть Code → Download ZIP.
2. Додайте цей архів до чату з Claude разом з інформацією, яку треба інтегрувати.
3. Claude поверне змінені файли й перелік того, що змінилося.
4. На GitHub відкрийте потрібну папку, оберіть Add file → Upload files і завантажте нові файли з тими самими назвами. Або відкрийте файл, натисніть значок олівця й вставте новий вміст.

## Де що лежить

- `config/search.js` — **логіка пошуку**: напрями пошуку, типи порушень, критерії оцінки ризику, інструкції для Claude. Нові правила, критерії чи напрями додаються сюди.
- `config/regions.js` — території пошуку: мови й маркетплейси для кожної.
- `config/classes.js` — класи МКТП з короткими описами.
- `config/settings.js` — модель, кількість пошуків і результатів, ліміти.
- `lib/watch.js` — аналіз зображення, збір даних для Claude, перевірка знайдених посилань.
- `lib/claude.js` — звернення до Claude API й розбір відповідей.
- `server.js` — сервер: пароль, ліміти, адреси `/api/...`.
- `render.yaml` — налаштування для розгортання на Render за одним посиланням.
- `public/` — сам сайт: `index.html` (розмітка й тексти), `styles.css` (вигляд), `app.js` (поведінка сторінки).
- `CHANGELOG.md` — історія змін за версіями.

## Запуск на своєму комп’ютері

Потрібен Node.js 20 або новіший.

```bash
npm install
cp .env.example .env    # впишіть у .env свій ключ
npm run dev
```

Сайт відкриється за адресою http://localhost:3000.

## Обмеження

Це попередній автоматичний скринінг, а не юридичний висновок. Чи є використання порушенням, визначає патентний повірений або суд з урахуванням реєстрації, дати пріоритету та фактичних обставин.
